# Streamlit CV · Belva YONTA

CV with a sidebar listing my EFREI courses. The **Data Visualization & BI** course page
(Prof. Dr Mano Joseph MATHEW, mano.mathew@efrei.fr) presents the assigned dataset
(New York yellow taxi trips, 15 January 2015), the analysis and its presentation.

## Run locally

```bash
pip install -r cv-streamlit/requirements.txt
streamlit run cv-streamlit/app.py
```

## Deploy (Streamlit Community Cloud)

share.streamlit.io → Create app → this repository, main file `cv-streamlit/app.py`.
